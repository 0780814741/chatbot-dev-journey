# Week 1: Pizza Order Bot

## Overview
This repository contains the Week 1 activity for the Chatbots Development course. The project implements a simple rule-based chatbot in Python that asks a user for a pizza size and topping, then confirms the order.

## Features
- Asks for pizza size (Small, Medium, Large) and re-asks if the input is invalid.
- Asks for one topping (Pepperoni, Mushrooms, Cheese) and re-asks if the input is invalid.
- Confirms the order back to the user once both choices are valid.
- Typing "bye" at any prompt ends the chat immediately.

## File Structure
- `Christian_TUYIZERE_Week1_Activity.ipynb` - Notebook containing the Pizza Order Bot code.
- `README.md` - Documentation for this project.

## How to Run
1. Open the `.ipynb` file in Google Colab or Jupyter Notebook.
2. Run the code cell.
3. Answer the prompts to place an order, or type "bye" to quit.
